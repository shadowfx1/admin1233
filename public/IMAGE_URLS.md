# Rayat Al Qanoon — Image URL Inventory

The website uses **29 images**. **16** have a direct online URL. **13** were created for this project and exist only as files in the project.

- Paths are relative to the website root (the folder that contains `index.html`).
- Each website page exists in Arabic (`page.html`) and English (`en/page.html`). It is listed once unless marked otherwise.
- Stock photo links are set to 1000 px wide, the same width the website uses.
- To use a direct URL, replace the local path in `src="…"`, `data-lb="…"` or `url(…)` with the link.
